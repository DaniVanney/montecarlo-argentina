# Simulación Monte Carlo de acciones argentinas

Proyecto personal de análisis de datos sobre acciones de los paneles
Líder y General del mercado argentino.

## Objetivo

Generar escenarios de precios de cierre en pesos argentinos para
horizontes de una a diez ruedas bursátiles mediante simulación Monte Carlo.

Evaluar los pronósticos frente a los precios observados y compararlos
con una referencia sencilla: mantener el último cierre conocido.

## Alcance inicial

- Utilizar yfinance como fuente inicial de datos.
- Desarrollar el análisis en Python y presentar resultados en Power BI.
- Trabajar sin suscripciones ni servicios pagos.
- Incorporar CEDEAR después de completar y validar la etapa de acciones.

## Estado del proyecto

Preparación del entorno y organización inicial.
Todavía no hay modelos implementados ni resultados de desempeño.

## Límites

Este proyecto tiene fines de investigación, aprendizaje y portfolio.
No ofrece asesoramiento personalizado ni ejecuta operaciones reales.
